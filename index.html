01 / Contexto del proyecto

Caso de estudio

Asignación y ajuste presupuestario de recursos para el desarrollo de software.

Gestión financiera de un proyecto tecnológico

El desarrollo de una aplicación informática requiere distribuir recursos económicos entre diferentes áreas de trabajo. Una asignación inadecuada puede provocar retrasos, problemas de calidad, infraestructura insuficiente o riesgos de seguridad.

Para representar esta situación se propone un modelo financiero que permite calcular ajustes presupuestarios para cinco categorías fundamentales de un proyecto de software. Las decisiones de asignación están relacionadas entre sí: aumentar los recursos de una categoría puede modificar las necesidades financieras de otras.

El sistema utiliza un conjunto de ecuaciones lineales simultáneas. Su solución permite determinar los ajustes presupuestarios que satisfacen las relaciones financieras establecidas en el modelo.

Procedencia de los datos: Los valores iniciales son datos hipotéticos de demostración, construidos para representar un proyecto tecnológico. No corresponden a estados financieros oficiales de una empresa. Todos los coeficientes y términos independientes pueden modificarse para estudiar otros proyectos.

Categorías presupuestarias

x₁ Desarrollo frontend
x₂ Desarrollo backend
x₃ Pruebas y calidad (QA)
x₄ Infraestructura y servicios cloud
x₅ Ciberseguridad
Unidad monetaria: Todos los resultados presupuestarios se expresan en miles de bolivianos (Bs).
02 / Simulación financiera

Escenarios de análisis

Los tres escenarios mantienen las mismas variables y estructura general, modificando los datos financieros y el condicionamiento de la matriz.

Escenario 01

Situación ideal

Proyecto estable, con distribución equilibrada de recursos, costos controlados y baja interdependencia entre categorías.

Escenario 02

Bajo estrés financiero

Incremento de costos operativos, mayores requerimientos tecnológicos y ajustes en las necesidades presupuestarias.

Escenario 03

Mal condicionado

Elevada interdependencia entre las categorías presupuestarias. Pequeñas variaciones pueden producir cambios importantes en la solución.

03 / Fundamentación matemática

Formulación del modelo

Representación del problema financiero mediante un sistema de ecuaciones lineales.

A · x = b Sistema lineal de cinco ecuaciones y cinco incógnitas (n = 5).

Matriz A

Representa las relaciones de costos, ponderaciones presupuestarias e interdependencias entre las cinco categorías del proyecto.

Vector x

Contiene los ajustes presupuestarios que se deben determinar para frontend, backend, QA, infraestructura y ciberseguridad.

Vector b

Representa los requerimientos financieros ponderados de cada categoría, expresados en miles de bolivianos.

Interpretación de los coeficientes: Los elementos diagonales aᵢᵢ representan la ponderación o sensibilidad financiera de cada categoría. Los elementos fuera de la diagonal aᵢⱼ representan la relación entre dos categorías presupuestarias. Un mayor valor de interacción representa una mayor dependencia dentro del modelo.
Condiciones matemáticas: La matriz A debe ser cuadrada, simétrica (A = Aᵀ) y definida positiva (xᵀAx > 0 para todo x distinto de cero). El simulador verifica estas propiedades antes de ejecutar los métodos numéricos, utilizando la simetría y la factorización de Cholesky.

09 / Interpretación técnica

Conclusiones y referencias

Fundamentación matemática, interpretación financiera y documentación bibliográfica.

Conclusiones del análisis

El método de Gradientes Conjugados permite resolver sistemas lineales simétricos y definidos positivos. Su aplicación al modelo financiero permite calcular ajustes presupuestarios entre las categorías del proyecto de software.

El precondicionamiento busca mejorar la convergencia del algoritmo, especialmente cuando las relaciones entre las variables generan problemas de condicionamiento numérico.

La precisión del resultado depende de la matriz, los términos independientes, el vector inicial y la tolerancia seleccionada.
